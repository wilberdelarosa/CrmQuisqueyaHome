La capacidad buscada es diseñar flujos inmobiliarios completos, mantener componentes coherentes y trasladar decisiones a una interfaz verificable. Los criterios de selección propuestos son: edición compartida, variantes/estados, tokens exportables, compatibilidad con el futuro stack, procedencia/licencia y salida sin rehacer todo. No hace falta comprar todas estas herramientas: cumplen funciones distintas.

## Decisión reversible propuesta

Elegir **un lienzo** (Figma o Penpot), **un generador para el piloto** (Stitch o Claude Design) y, si se confirma un stack React compatible, una base común de componentes y Storybook. Usar 21st para necesidades identificadas. Mantener tokens y contratos en archivos del proyecto para que cambiar de herramienta visual no obligue a cambiar reglas o API.

Estrategia inicial: E4, construir el sistema específico estudiando patrones; E3/E2 solo para piezas con procedencia y licencia verificadas. No se elige todavía una plantilla completa ni un CRM backend por su aspecto.

No puntuamos estas siete herramientas como sustitutos equivalentes: una tabla de generación contra un catálogo ejecutable produciría un ganador ficticio. Para el piloto comparable Stitch/Claude Design y Figma/Penpot, usar cobertura funcional 20, licencia 15, mantenimiento 15, seguridad 15, integración 10, salida 10, costo a tres años 10 y UX 5. Los valores quedan pendientes de acceso, requisitos aceptados y pruebas; no se supone seguridad por marca.

Prueba propuesta, aislada y con datos sintéticos: resolver las mismas tres recetas —bandeja de leads, ficha de oportunidad y edición/publicación de propiedad—; registrar tiempo de adaptación, exportación reabrible, tokens preservados, teclado, dos anchos de pantalla y ocho estados. Éxito: flujos comprendidos por usuarios representantes, handoff editable fuera del generador y ninguna regla crítica solo representada por una imagen. Fallo: exportación inutilizable, licencia no resuelta o adaptación superior al ahorro observado. El presupuesto se calcula después: licencias y consumo + hosting/almacenamiento si aplica + horas de mantenimiento + migración/salida durante 36 meses. No se promete ahorro sin medirlo.

Reinvestigar antes de comprar, generar con datos privados o integrar código; las características y cuotas pueden cambiar. D03 revisa encaje; D12 revisa licencias y exposición de información antes de adopción.
